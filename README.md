# Minecraft utilities

**[Pearl Pull tray apps and installers](pearl-pull/TRAY-APPS.md)** are the easiest
way to use this on two Windows PCs. Install Button on PC 1 and Receiver on PC 2.
They start with Windows, stay in the tray, and include graphical setup,
Stream Deck Neo support, crash recovery where permitted, and bounded log files.

[Pearl Pull](pearl-pull/README.md) lets an F8 press on one Windows PC request one
right-click in Minecraft Bedrock on a second PC over your home network. It can
also be triggered with a [Stream Deck Neo](pearl-pull/STREAM-DECK-NEO.md), with
a custom pearl icon included. The [script version](pearl-pull/README.md) remains
available for development and manual diagnostics.

[Windows security and startup](pearl-pull/STARTUP-AND-WINDOWS-SECURITY.md)
explains Smart App Control limitations and how to keep the utility running
after Windows sign-in.
